# Media Pembelajaran Interaktif SKI Kelas 10: Khulafaur Rasyidin 🕌✨

Aplikasi Web Media Pembelajaran Interaktif untuk Mata Pelajaran **Sejarah Kebudayaan Islam (SKI) Kelas 10 SMA/MA** materi **Perkembangan Islam Masa Khulafaur Rasyidin**.

Dilengkapi dengan:
- 📖 **Modul Materi 4 Khalifah** (Abu Bakar as-Siddiq, Umar bin Khattab, Utsman bin Affan, Ali bin Abi Thalib).
- ⏳ **Linimasa Sejarah Interaktif** (Peristiwa penting 11 H - 40 H).
- 🖼️ **Galeri Visual & Lightbox Zoom** (Ilustrasi sejarah beresolusi tinggi).
- 🎮 **Kuis Interaktif Ala Kahoot (20 Soal - 3 Model)**:
  - Model 1: Pilihan Ganda (8 Soal)
  - Model 2: Benar / Salah (6 Soal)
  - Model 3: Menjodohkan / Pasangkan Kebijakan (6 Soal)
- ⏱️ **Timer 20 Detik, 🔥 Streak Combo, Poin Kecepatan, Confetti, & Sound Effects**.
- 📱 **Mobile App Bottom Toolbar** (Sangat nyaman digunakan di Smartphone / HP).

---

## 🚀 Cara Menjalankan

### 1. Langsung di Browser (File HTML)
Buka file `index.html` langsung di browser favorit Anda (Chrome, Edge, Firefox, Safari).

### 2. Menjalankan Server Localhost (Node.js)
```bash
node server.js
```
Akses di browser: `http://localhost:8000`
